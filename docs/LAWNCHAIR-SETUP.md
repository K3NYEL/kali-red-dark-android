# Lawnchair setup guide

Recommended starting point for the **Kali Red Dark** look on a Cubot KINGKONG ACE 2 running Android 14. Lawnchair menu names can vary by version.

## Target appearance

- Main background: near-black `#0b0b0d`
- Secondary surfaces: `#09090b`
- Accent: crimson red `#ec0101`
- Main text: `#e8e8e8`
- Secondary text and separators: graphite gray, close to `#777777`

## 1. Open Lawnchair settings

1. Go to the home screen.
2. Press and hold an empty area.
3. Open **Home settings**.

## 2. Set a clean layout

Use these as starting values, not strict requirements. Adjust them if icons or widgets feel cramped on your display.

| Setting | Starting recommendation |
|---|---|
| Home screen grid | 5 columns × 7 rows |
| Icon size | Around 90–100% |
| Home screen labels | Keep enabled at first for readability |
| Dock | 4–5 frequently used apps |
| Folders | Group apps by purpose; avoid filling the first screen |
| Widgets | One clock/date widget near the top; leave open space around it |

The grid and dock can have separate settings. If your Lawnchair version uses different labels, look for **Home screen**, **Layout**, **Icons**, and **Dock**.

## 3. Apply the dark red accent

1. Open **Home settings → General**.
2. Open **Accent color**.
3. Choose **Custom** if your installed version offers it.
4. Select or enter `#ec0101` if hexadecimal input is available.
5. Keep the color style restrained and use the dark theme where offered.

If custom hex input is unavailable, choose the closest red preset. Android's system color palette and Lawnchair's accent color are separate controls, so the launcher accent may not recolor every system panel.

## 4. Configure icons

Lawnchair supports installed icon packs and, where available, Android themed icons. A compatible monochrome icon source can create a consistent look, but not every app is guaranteed to have a matching icon.

1. Open **Home settings → General → Icon style** (the wording can vary).
2. Select an installed compatible pack, or enable themed icons if the option is present.
3. If icons become unexpectedly tinted, turn off **Tint with accent color**.
4. To customize one app, long-press its home-screen icon and look for **Customize** or the pencil icon.

Do not install a random APK just because it claims to be a theme. Prefer trusted app stores or the icon project's official release page.

## 5. Add widgets and arrange the home screen

1. Long-press an empty area and choose **Widgets**.
2. Add a clock/date widget that stays readable on a dark background.
3. Keep the first screen simple: clock/date near the top, essential apps in the middle, dock at the bottom.
4. Prefer widget text in soft white or gray, with red used only for accents.

Widget appearance is controlled by each widget's app; Lawnchair cannot force every widget to use the same colors.

## 6. Check Android 14 system appearance

Open **Settings → Wallpaper & style** and enable the dark theme if available. Apply the eventual Kali Red Dark wallpaper when it is added to the repository. If Android offers wallpaper-derived colors, check whether a dark red option is available.

Manufacturer firmware may limit custom system colors. Lawnchair changes the home screen, not the entire Android interface.

## Troubleshooting

- **No custom accent option:** use the nearest red preset and keep the wallpaper dark.
- **Icons look too colorful:** try a compatible monochrome/themed icon source or disable accent tint.
- **Widgets are cramped:** reduce the number of home-screen rows or use a smaller widget.
- **A setting is missing:** your Lawnchair version may organize it differently; check its own help or share a screenshot of the settings page.

## Current status

This guide describes settings to apply manually. The repository does not yet contain an installable theme APK, an icon pack, or the final wallpaper image.
