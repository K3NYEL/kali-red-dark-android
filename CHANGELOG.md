# Changelog

Notable repository changes are recorded here. This project is a documentation and asset kit; entries do not imply an installable theme release unless explicitly stated.

## 0.1.0 — Initial foundation

- Added the Android-focused project structure and color token JSON.
- Added installation and Lawnchair manual configuration guides.
- Documented target-device limitations and the absence of an installable theme.
- Defined requirements for future wallpaper, icon pack, and preview assets.
- Added contribution guidelines.

## Unreleased

- Added a Python validation script for the palette and required project metadata.
- Added a GitHub Actions workflow to run validation on pushes, pull requests, and manual dispatch.
- Added an original vector wallpaper source and a workflow to render a 1080 × 2400 PNG artifact.
- Added ignore rules for local/editor files and temporary exports.
- Custom icon pack and preview images are still pending.
- No APK or system-wide theme package is available.
