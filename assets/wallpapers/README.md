# Wallpapers

**Status: not yet available.** This directory currently contains documentation only; no wallpaper file has been committed.

## Planned visual direction

- Near-black background: `#0B0B0D`
- Bright-red accent: `#FF0000`
- Original theme red retained as an alternate: `#EC0101`
- Minimal composition with an original red dragon-inspired emblem
- Portrait layout with quiet space near the top and bottom for Android UI

The emblem must be original artwork, not a copy of an official logo. The eventual asset should include a high-resolution master, a phone-ready export, and source/license metadata.

See the [asset specifications](../../docs/ASSET-SPEC.md) before adding files.
