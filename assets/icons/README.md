# Icon assets

**Status: not yet available.** This directory currently contains documentation only; there is no installable Kali Red Dark icon pack here.

Before adding icon artwork, follow the [asset specifications](../../docs/ASSET-SPEC.md). Confirm the target launcher's supported icon-pack format, use original artwork or assets with clear usage rights, and document the apps covered and fallback behavior.

A folder of image files alone does not install or apply icons. Until a compatible package exists, configure icons manually through Lawnchair only where that option is available.
